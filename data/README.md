# Data

This project uses the Online Retail II dataset from the UCI Machine Learning Repository.

Dataset source: https://archive.ics.uci.edu/dataset/502/online+retail+ii

The original Excel dataset is not included in this GitHub repository. To reproduce the analysis, download `online_retail_II.xlsx` from the source above and place it in this folder.

Run the notebooks in numerical order, starting with `notebooks/01_data_cleaning_rfm.ipynb`. The notebooks generate the intermediate datasets and analytical outputs used in subsequent stages.
